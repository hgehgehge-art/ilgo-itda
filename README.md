# 읽고, 잇다 — 해외문학회의 읽기와 대화를 잇는 웹사이트

기준일: 2026년 10월 20일. **일정은 공개 Google Sheets에서 직접 읽습니다. Supabase 연결 실패 때문에 온라인 신청·취소는 현재 정상 동작을 확인하지 못했습니다.** 토론 기록 파일 만들기와 독서 지도는 Supabase 없이 사용할 수 있습니다.

## 1. 목적과 서비스 배경

한국외대 중앙동아리 해외문학회에서는 종이 장부로 대출을 기록하고, 카카오톡 투표로 세미나 참석자를 모아 회장이 직접 마감했습니다. 책을 찾고, 일정을 확인하고, 함께 나눈 대화를 남기는 일을 한곳으로 모으는 것이 이 프로젝트의 목적입니다.

제작자는 Social Science & AI 융합학부 24학번이자 해외문학회 회장입니다. AX·DX 전환에 관심이 있으며 서비스 기획자를 꿈꾸고 있습니다. 운영상의 불편을 작은 웹 기능으로 바꾸는 개인 홈페이지 과제입니다.

## 2. 주요 사용자

주요 사용자는 **세미나 일정을 확인하고 독서토론을 정리하려는 해외문학회 회원**입니다. 회원 가입 없이 이용합니다. 중간 MVP에서 외부 서버 없이 끝까지 확인할 수 있는 흐름은 **토론 텍스트 입력 → 키워드 확인·수정 → 미리보기 → 기록 파일 내려받기**입니다.

## 3. 공개 주소와 기능

- [홈페이지](https://hgehgehge-art.github.io/ilgo-itda/): 제작자·관심 분야·프로젝트 설명.
- [책장](https://hgehgehge-art.github.io/ilgo-itda/books.html): 제목·작가·권번호 검색, 대출 가능 필터. 대출 시트 미연결로 대출 상태는 예시입니다.
- [세미나](https://hgehgehge-art.github.io/ilgo-itda/seminars.html): 공개 시트의 일정 직접 조회. 신청 서버에 연결되지 않으면 신청·취소를 중단하고 안내합니다.
- [그날의 토론](https://hgehgehge-art.github.io/ilgo-itda/discussions.html): 텍스트 붙여넣기 또는 txt/md 파일, 단어 빈도 기반 키워드, 직접 작성하는 요약·질문, 검토 후 JSON 내려받기.
- [독서 지도](https://hgehgehge-art.github.io/ilgo-itda/places.html): OpenStreetMap 지도, 장소 검색·분류, 장소 추천서 JSON 내려받기. 검토된 실제 장소는 아직 등록하지 않았습니다.
- [GitHub 저장소](https://github.com/hgehgehge-art/ilgo-itda): 구현·수정 기록.

## 4. 사용·실행·수정 방법

토론 화면의 ‘예시로 체험하기’를 누르거나 본인이 공개할 수 있는 텍스트를 입력합니다. 키워드를 뽑고 불필요한 단어를 삭제합니다. 요약·질문·인용문을 검토하고 이름·학번·연락처를 지운 뒤 확인란을 체크하면 기록 파일을 내려받을 수 있습니다. **서버로 제출되거나 공개 게시되는 기능은 아닙니다.** 새로고침 전에 파일을 저장하세요.

지도에서 추천하려는 장소의 이름·주소·분류·추천 이유를 적고 확인란을 체크하면 검토 대기 상태의 추천서가 내려받아집니다. 네이버 링크는 선택 사항입니다. 내 네이버 저장 목록 링크는 각자 로그인한 계정의 목록을 여는 기능이며 저장 장소를 자동으로 가져오지 않습니다.

로컬 실행은 Node.js 20 이상에서 저장소 폴더를 열고 다음과 같이 합니다. 별도 설치 패키지가 없습니다.

```sh
node scripts/serve.mjs
```

브라우저에서 http://localhost:8000 을 엽니다. HTML 파일을 더블클릭하는 file:// 방식은 데이터 읽기에 적합하지 않습니다.

| 수정 내용 | 위치 |
| --- | --- |
| 소개·문구·디자인 | index.html, 각 HTML, assets/css/style.css |
| 일정 원본·학기 연도 | assets/js/direct-sheets.js와 공개 Google Sheets |
| 공개 장소 목록 | data/places.json — 검토 후 status를 published로 지정 |
| 토론 편집·키워드 규칙 | assets/js/discussions.js, assets/js/keywords.js |
| 예약 서버 연결 | assets/js/config.js, assets/js/reservations-api.js |

브라우저 검증 스크립트는 설치된 Chrome과 Playwright가 있는 개발 환경에서 실행합니다.

```sh
PLAYWRIGHT_PATH=/설치된/playwright/절대경로 node scripts/check-mvp-ui.cjs
```

## 5. 데이터 출처와 갱신

- 일정: 동아리 26-2 주간세미나 공개 시트. 페이지를 열 때 직접 CSV를 요청합니다. Google의 응답 캐시 때문에 즉시 반영은 보장하지 않습니다. 실패하면 기존 서버 경로를 시도합니다. 시간·장소가 비면 18시·동아리방으로 처리합니다.
- 원본 시트는 브라우저에서 접근 가능한 공개 자료입니다. 화면에서 발제자·비고를 제외해도 원본 공개 범위는 바뀌지 않습니다. 회원 기록과 비공개 대출 시트를 이 경로에 연결하면 안 됩니다.
- 책장: 기존 민음사 세계문학전집 목록과 예시 대출 데이터. 실물 대출 상태와 다를 수 있습니다.
- 오늘의 한 문장: 한국어 명언 API를 기존 GitHub Actions가 받아 data/today-quote.json에 저장합니다. 브라우저에서는 API를 직접 호출하지 않습니다.
- 지도: OpenStreetMap. 장소 데이터는 아직 빈 목록입니다. 네이버 개인 저장함 주소만으로 다른 방문자에게 장소 목록을 공유할 수 없습니다.
- 토론: 사용자가 입력한 텍스트를 브라우저에서 분석합니다. AI 요약이 아니라 단어 빈도 기반 키워드입니다. 원문은 서버로 보내지 않으며 내려받는 JSON에서도 제외합니다.

## 6. 검증 기록

2026-10-20 로컬 Chrome에서 19개 UI 점검이 통과했습니다. 외부 응답을 대체한 화면 테스트이며 실제 예약 성공을 의미하지 않습니다. [전체 결과](docs/mvp-check-results.json), [검증 코드](scripts/check-mvp-ui.cjs)를 확인할 수 있습니다.

| 입력 | 기대 결과 | 실제 결과 | 판단 | 근거 |
| --- | --- | --- | --- | --- |
| 5개 화면, 360px | 가로 넘침 없음 | 없음 | 통과 | 360px 항목 5개 |
| 빈 토론 제목 | 입력 안내 | 안내 표시 | 통과 | 빈 제목 안내 |
| 예시·텍스트 파일 | 키워드와 미리보기 | 정상 생성 | 통과 | 예시·파일 항목 |
| 토론 JSON 다운로드 | 원문·관리 코드 제외 | 제외 확인 | 통과 | 기록 파일 항목 |
| HTML 형태 키워드 | 코드로 실행되지 않음 | 실행되지 않음 | 통과 | HTML 실행 방지 |
| 장소 없음·분류 불일치 | 빈 상태 안내 | 안내 표시 | 통과 | 지도·분류 항목 |
| 잘못된 장소 링크 | 다운로드 차단 | 차단 | 통과 | 잘못된 링크 차단 |
| 지도 데이터 HTTP500 | 오류와 재시도 | 표시·복구 | 통과 | 지도 오류·재시도 |
| 추천서 다운로드 | 검토 대기 JSON | pending 확인 | 통과 | 추천서 내려받기 |
| 키보드 Tab | 초점 표시 | 표시 확인 | 통과 | 키보드 항목 |
| 실제 Google CSV 요청 | 일정 응답 수신 | HTTP200 | 통과 | 공개 사이트 출처의 Chrome 요청 |
| 실제 Supabase sheet_rows 요청 | 정상 응답 | Failed to fetch | 실패 | 2026-10-20 Chrome 요청 |

실제 신청·취소, 동시 신청, DB 접근 제한, 공개 장소 핀과 온라인 토론 게시의 전체 연동은 이번 점검에서 확인하지 못했습니다.

## 7. 한계와 다음 작업

온라인 신청·취소에는 신뢰할 수 있는 서버 저장소가 필요합니다. 일정 직접 조회 복구가 예약 서버 복구를 뜻하지는 않습니다. 현재는 연결 실패 시 운영진 문의를 안내합니다. 대출 상태는 예시이며, 실제 시트 연결 전까지 운영 데이터로 사용할 수 없습니다.

토론 온라인 게시와 AI 요약은 준비 중입니다. DISCUSSIONS_ENABLED는 false이며 SQL 초안은 실제 적용·검증하지 않았습니다. 기록·추천서 다운로드는 기기에 파일을 저장하며 운영진에게 자동 전달하지 않습니다. 공개 전에는 개인정보와 인용문을 사람이 검토해야 합니다.

실제 장소 핀을 넣으려면 공개 공유 목록이나 장소별 링크·주소가 필요합니다. 개인 네이버 저장함은 가져오지 않았습니다. Supabase 공개 키는 브라우저용 키이며 관리자 비밀키는 넣지 않습니다. 현재 공개 예약 서버의 접근 통제는 별도 재점검이 필요합니다.
